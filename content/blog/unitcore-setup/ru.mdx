Бюджет в Unitcore ведут разговором: «запиши 1200 на продукты вчера», «сколько я потратил
на еду в июле». Заполнять формы не нужно, потому что основной интерфейс приложения —
[MCP](https://modelcontextprotocol.io)-сервер, к которому Claude подключается как к
своему инструменту.

Подключение занимает пару минут и делается один раз на аккаунт: коннектор, добавленный
в браузере, дальше работает и в десктопном приложении, и на телефоне.

>
  Добавить Unitcore в Claude
</InstallButton>

Если вы добавляете коннектор руками, вот единственное значение, которое придётся ввести:

<CopyField label="Remote MCP server URL" value={MCP_URL} />

Ни ключей, ни токенов, ни паролей вводить никуда не нужно — доступ выдаётся через ваш
обычный аккаунт Unitcore.

<Callout type="warning">
  **Одна настройка, которую придётся поставить руками.** В диалоге добавления, в блоке
  **OAuth client**, выберите **«No client ID — register one automatically»**. Вариант с
  заранее известными client metadata сервер авторизации Unitcore не объявляет, и
  подключение оборвётся на возврате из браузера. Почему так — в шаге 3.
</Callout>

## Перед началом

- **Войдите в Unitcore в этом же браузере.** Тогда на шаге авторизации вы сразу
  увидите экран согласия, без повторного входа.
- **Аккаунт Claude подойдёт любой, включая бесплатный.** На бесплатном тарифе
  доступен один свой коннектор, так что слот стоит потратить осознанно.
- **Team или Enterprise:** свои коннекторы добавляет владелец организации. Ему нужна{' '}
  <a href={claudeInstallUrl('organization')} target="_blank" rel="noopener noreferrer">та же ссылка, но на админскую страницу</a>;
  вам после этого останется нажать **Connect**.

## Шаг 1. Откройте диалог коннектора

Кнопка выше открывает его сразу. Руками — так:

| Где вы работаете | Что сделать |
| --- | --- |
| **Claude в браузере** | Аватар в правом верхнем углу → **Settings** → **Customize** → **Connectors** |
| **Claude Desktop** | `⌘ ,` или `Ctrl ,` → **Customize** → **Connectors** |
| **Claude на телефоне** | Коннекторы добавляются только с компьютера. Добавленный один раз, он появится на телефоне сам |

В разделе **Connectors** нажмите **+** и выберите **Add custom connector**.

## Шаг 2. Имя и адрес

<CopyField label="Name" value={CONNECTOR_NAME} />

<CopyField label="Remote MCP server URL" value={MCP_URL} />

Имя — просто подпись, по которой вы узнаете своё подключение в списке коннекторов; на
права оно не влияет. Дальше Claude проверит адрес и подставит настройки авторизации сам.

## Шаг 3. OAuth client

Единственный пункт, который стоит поставить осознанно:

> **No client ID — register one automatically**

Причина видна в том, как устроено подключение. Claude сначала запрашивает
`/.well-known/oauth-protected-resource` — документ из
[RFC 9728](https://datatracker.ietf.org/doc/html/rfc9728), который сообщает, какой сервер
авторизации выдаёт токены для этого ресурса. Тот сервер объявляет у себя
`registration_endpoint` и не объявляет client id metadata document, а значит рабочий путь
здесь ровно один: клиент регистрируется динамически и получает свежий client id на это
подключение.

Остальное трогать не нужно:

| Поле | Значение |
| --- | --- |
| **Authentication** | вход через ваш аккаунт Unitcore, определяется автоматически |
| **Request headers** | оставьте пустым — API-ключей здесь нет |
| **Advanced → Transport** | подставится из адреса |

<Callout type="warning">
  Настройки авторизации нельзя изменить у уже добавленного коннектора. Если ошиблись —
  **Remove** и добавить заново.
</Callout>

Нажмите **Add**.

## Шаг 4. Вход и экран согласия

В списке коннекторов появится карточка. Нажмите **Connect** — откроется окно браузера, и
если вы ещё не вошли в Unitcore, сначала будет форма входа.

Дальше — экран согласия Unitcore. На нём стоит действительно посмотреть три строки:

- **Client** — имя клиента, который просит доступ;
- **Redirects to** — куда вас вернут; у Claude это `https://claude.ai/api/mcp/auth_callback`;
- **Signed in as** — ваш ли это аккаунт Unitcore.

Кнопка **Allow access** выдаёт токен, **Deny** завершает процесс, и доступ не выдаётся.
После подтверждения окно закроется само, а карточка коннектора станет активной.

## Шаг 5. Включите коннектор в разговоре

Коннектор подключён к аккаунту, но в каждом чате включается отдельно: в поле ввода
нажмите **+** → **Connectors** и включите переключатель рядом с Unitcore.

## Шаг 6. Проверьте, что всё работает

<CopyField multiline value="Покажи мои пространства в Unitcore" />

Claude попросит подтвердить вызов инструмента — нажмите **Allow** или **Allow always**,
чтобы не подтверждать каждый раз. В ответе должно быть ваше личное пространство: оно
создаётся автоматически при регистрации. Видите его — подключение завершено.

## Первые сценарии

Готовые фразы, можно копировать как есть.

<CopyField multiline value="Запиши в Unitcore: продукты, 1200 рублей, вчера" />

<CopyField
  multiline
  value="Запиши покупку на 2340: молоко 89, хлеб 65, сыр 420, остальное — продукты"
/>

<CopyField multiline value="Сколько я потратил в этом месяце? Разбей по категориям" />

Три вещи про модель данных стоит знать, потому что они объясняют получаемые ответы:

- **Пространства** — это область бюджета. Личное создаётся при регистрации и
  используется всегда, когда вы не назвали другое. Пространством можно поделиться с
  другими людьми.
- **Категории** живут внутри пространства и бывают либо `expense`, либо `income`. Если
  подходящей нет, Claude предложит создать новую.
- **Транзакции** состоят из позиций, суммы которых всегда положительные. Знак определяет
  вид категории, и решается это в базе — не в клиенте и не вашей формулировкой. Валюта по
  умолчанию — рубль.

## Что Claude умеет

Восемь инструментов, разделённых по тому, что они трогают:

| Чтение | Запись |
| --- | --- |
| `list_spaces` | `create_space` |
| `list_categories` | `rename_space` |
| `list_transactions` | `create_category` |
| `summary` | `create_transaction` |

`summary` отвечает на большинство вопросов: он возвращает суммы расходов и доходов по
категориям за период.

| Вы говорите | Claude вызывает |
| --- | --- |
| «Какие у меня пространства?» | `list_spaces` |
| «Заведи пространство "Отпуск"» | `create_space` |
| «Какие у меня категории расходов?» | `list_categories` |
| «Заведи категорию на транспорт» | `create_category` |
| «Запиши 1200 на продукты вчера» | `create_transaction` |
| «Покажи траты на кафе за август» | `list_transactions` |
| «Сколько я потратил на еду в июле?» | `summary` |

## Чего подключённый клиент не может

- **Не может удалять.** Удалить пространство, профиль или участника OAuth-токеном
  невозможно: политики в базе пропускают удаление, только когда в токене нет `client_id`,
  то есть из веб-сессии, где человек видит диалог подтверждения.
- **Может вообще не иметь права на запись.** Запись разрешена клиентам из списка,
  сверяемого по имени и redirect URI. Не перечисленный клиент может читать и больше
  ничего — поэтому если чтение работает, а запись молча не проходит, причина в этом.

Стоит уточнить, потому что звучит похоже на права доступа, но устроено иначе: это **не
OAuth-scope**. Токен не несёт ничего вроде «только чтение» — решение каждый раз принимают
политики в Postgres.

## Почему это безопасно подключать

Подключение AI-клиента к своим финансам заслуживает большего, чем успокаивающая фраза.
Правило такое: **инструмент действует от имени того, кто его вызвал, и ни от чьего
больше**, и три вещи не дают этому правилу размыться:

- **Изоляцию обеспечивает Postgres, а не код инструментов.** Запрос несёт ваш
  OAuth-токен, и что вернётся, решает Row Level Security. Ничто в телах инструментов не
  обеспечивает изоляцию — значит, ничто в них не может её случайно сломать.
- **Принимаются только OAuth-токены.** Проверка требует claim `client_id`, поэтому
  утащенная из браузера сессия ключом к этому серверу не является.
- **Service-role ключ до инструментов не дотягивается.** Этот ключ обходит RLS, и сборка
  падает, если код MCP хотя бы прочитает переменную окружения с `SECRET` или
  `SERVICE_ROLE`.

Есть и сквозной тест: он гоняет все читающие инструменты от одного пользователя и падает,
если в ответе всплыл идентификатор другого.

## Как отключить

- **Точечно:** в карточке коннектора любому инструменту можно поставить разрешение
  **Blocked**. Заблокируйте `create_transaction` и `create_category` — Claude сможет
  читать и считать, но ничего не запишет.
- **Целиком:** **Customize** → **Connectors** → Unitcore → **Remove**. Клиент теряет
  возможность продлевать доступ; выданный токен короткоживущий и обновляется Claude
  самостоятельно, пока подключение существует.

## Если что-то пошло не так

| Что вы видите | Что это значит |
| --- | --- |
| После подтверждения вернулись с ошибкой авторизации | Почти всегда дело в настройке из шага 3. У существующего коннектора её не изменить: **Remove** и добавить заново, выбрав **«No client ID — register one automatically»** |
| **Connect** ничего не открывает | Браузер заблокировал всплывающее окно. Разрешите всплывающие окна для claude.ai и повторите |
| Claude отвечает, что у него нет доступа к Unitcore | Коннектор не включён в этом чате: **+** → **Connectors** → Unitcore |
| `401` | Токен протух либо использован токен браузерной сессии. Переподключите клиент |
| `No access token.` | Запрос дошёл до сервера без bearer-токена |
| `No personal space found. Pass space_id explicitly.` | Нет пространства по умолчанию — назовите пространство в запросе |
| Список пространств пуст | Вы вошли в другой аккаунт Unitcore. Удалите коннектор, выйдите из лишнего аккаунта и подключитесь заново |
| Чтение работает, запись — нет | Клиента нет в списке разрешённых на запись |
| Не вижу пункт **Add custom connector** | Тариф Team или Enterprise: коннектор сначала добавляет владелец организации |

## Другие клиенты

Адрес сервера один и тот же, и его понимают Cursor, ChatGPT и другие клиенты с
поддержкой MCP — чтение в них заработает так же. Но список разрешённых на запись сейчас
состоит из одного Claude, поэтому в остальных клиентах ждите режим только для чтения: это
не поломка подключения, а то самое правило из раздела выше.

## Частые вопросы

**Нужна ли подписка Claude?**
Нет. Свои коннекторы работают и на бесплатном тарифе, но там доступен только один — если
у вас уже подключён другой сервис, слот придётся освободить.

**Работает ли это на телефоне?**
Да. Claude обращается к Unitcore из своего облака, а не с вашего устройства, поэтому
подключение, сделанное один раз в браузере, работает и в мобильном приложении.

**А если я подключусь с рабочего компьютера — коллеги увидят мой бюджет?**
Нет. Доступ привязан к вашей учётной записи Unitcore, а не к устройству или организации.

**Что Claude видит из моих данных?**
Только то, что запрашивает в момент ответа: пространства, категории, транзакции и итоги.
И ровно в тех границах, которые вы видите сами в приложении.
